# OpenDSS CIM Roundtrip Benchmark

This benchmark checks plain CIM interoperability between OpenDSS and VeraGrid on one real OpenDSS-exported feeder, not a hand-made toy case.

Flow:

`OpenDSS CIM -> VeraGrid import -> VeraGrid power flow -> VeraGrid CIM export -> VeraGrid re-import -> VeraGrid power flow`

Pass condition:

- both VeraGrid power flows converge
- the roundtrip voltage vector matches the first solve within `1e-6`

## Benchmark Files

- `ieee13cdpsm.xml`
  - main OpenDSS combined CIM100 fixture used by VeraGrid
- `ieee13_cdpsm_roundtrip.py`
  - standalone runner for the benchmark
- `ieee13cdpsm_roundtrip_export.xml`
  - generated by the runner, not committed

## Fixture Provenance

`ieee13cdpsm.xml` was generated from the official OpenDSS command-line distribution under `wine`, using the bundled OpenDSS CIM export script.

Upstream OpenDSS inputs used to generate the fixture:

- `opendsscmd.exe` from the official OpenDSSCmd package
- bundled `cim_test.dss`
- bundled `IEEE13_CDPSM.dss`
- bundled `IEEE13_Assets.dss`
- bundled `IEEELineCodes.DSS`
- bundled UUID data files:
  - `IEEE13Nodeckt_Base_UUIDS.dat`
  - `IEEE13NodecktAssets_Base_UUIDS.dat`

The direct OpenDSS command that emitted the fixture was:

```text
redirect cim_test.dss
```

That script produces:

- `ieee13cdpsm.xml`
- `ieee13assets.xml`
- fragment exports such as `ieee13cdpsm_FUN.XML`, `ieee13cdpsm_TOPO.XML`, `ieee13cdpsm_SSH.XML`

Only `ieee13cdpsm.xml` is needed for this VeraGrid benchmark.

## Local VeraGrid Inputs

To run the roundtrip benchmark inside this repo you only need:

- `benchmarks/roundtrips/cim/opendss/ieee13cdpsm.xml`
- `benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py`
- the VeraGrid source tree under `src/`

## System Setup

Minimal setup to run the VeraGrid-side benchmark:

- Linux
- `python3`
- the VeraGrid Python dependencies already installed for this repo

Minimal setup to regenerate the OpenDSS fixture from upstream:

- Linux
- `python3`
- `wine`
- official `OpenDSSCmd` Windows package installed in a wine prefix

This benchmark does not require `wine` unless you want to regenerate the source fixture from OpenDSS yourself.

## How To Run

From the repo root:

```bash
python3 benchmarks/roundtrips/cim/opendss/ieee13_cdpsm_roundtrip.py
```

Expected output ends with:

```text
ok
```

## Regression Test

The same fixture is also covered by the CIM test file:

```bash
cd src
python3 -m pytest tests/FileFormats/CIM/test_cim_opendss_interop.py -q
```

## Regenerate The Fixture From OpenDSS

If you want to reproduce `ieee13cdpsm.xml` from OpenDSS instead of using the committed fixture:

1. Install the official OpenDSSCmd Windows package into a wine prefix.
2. Start the OpenDSS prompt from its bundled `test` directory.
3. Run:

```text
redirect cim_test.dss
```

4. Copy the emitted `ieee13cdpsm.xml` into this folder.

The bundled OpenDSS test directory is used on purpose here because it already carries the exact DSS inputs and UUID files expected by `cim_test.dss`.
