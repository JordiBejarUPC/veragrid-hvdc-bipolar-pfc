# Limit (signal + parameter input)

This is Basic Block Catalog type `322` (`Limit [sp`). It applies the declared limiting or nonlinear relation to its input signals.

## Behaviour

- Library location: `Native / Limits and Nonlinearities / Limiters`.
- Inputs: 3.
- Outputs: 1.
- Declared states: 0.
- Configurable parameters: 2.
- The imported definition is fully supported by the Dynamic Editor catalogue.
