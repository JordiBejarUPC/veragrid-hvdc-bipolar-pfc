# K(1+sTb)/(1+sTa)

This is Basic Block Catalog type `304` (`K(1+sTb)/(1+sTa)`). It processes measurement or control signals for use inside a dynamic control model.

## Behaviour

- Library location: `Native / Control and Measurement / Controllers`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 1.
- Configurable parameters: 3.
- The imported definition is fully supported by the Dynamic Editor catalogue.
