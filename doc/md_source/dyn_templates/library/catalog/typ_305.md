# K(1+sTld)/(1+sTlg) (feedback)

This is Basic Block Catalog type `305` (`K(1+sTld)/(1+sTlg) _fb`). It processes measurement or control signals for use inside a dynamic control model.

## Behaviour

- Library location: `Native / Control and Measurement / Controllers`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 1.
- Configurable parameters: 3.
- The imported definition is fully supported by the Dynamic Editor catalogue.
