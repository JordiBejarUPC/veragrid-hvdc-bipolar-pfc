# p.u. -> rpm

This is Basic Block Catalog type `560` (`p.u. -> rpm`). It processes measurement or control signals for use inside a dynamic control model.

## Behaviour

- Library location: `Native / Control and Measurement / Measurements and Units`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 0.
- Configurable parameters: 2.
- The imported definition is fully supported by the Dynamic Editor catalogue.

## Characteristic equations

$$
0 = (n - \frac{speed \cdot freqbase \cdot 60}{Zp})
$$

## Interface table

| Category | Name | Meaning | Units |
| --- | --- | --- | --- |
| Input | `speed` | Input signal consumed by the block | model-dependent |
| Output | `n` | Output signal produced by the block | model-dependent |
| Parameter | `Zp` | Configurable model parameter | model-dependent |
| Parameter | `freqbase` | Configurable model parameter | model-dependent |

## Editing notes

Use General options for numeric parameter values and the DAE tab for symbolic variables and equations. Changing an Output flag only controls whether a variable is exported; it does not remove the variable from the model.
