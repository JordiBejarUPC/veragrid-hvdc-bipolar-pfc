# (K+sTb)/(1+sTa)

This is Basic Block Catalog type `302` (`(K+sTb)/(1+sTa)`). It represents a continuous-time dynamic operation, including any declared internal states.

## Behaviour

- Library location: `Native / Continuous / Transfer Functions and Filters`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 1.
- Configurable parameters: 3.
- The imported definition is fully supported by the Dynamic Editor catalogue.
