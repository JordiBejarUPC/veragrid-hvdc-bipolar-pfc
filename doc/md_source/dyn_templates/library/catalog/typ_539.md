# Park transform (dq)

This is Basic Block Catalog type `539` (`Park transform (dq)`). It converts signals between the coordinate systems or units identified by the block name.

## Behaviour

- Library location: `Native / Transforms / Clarke, Park and dq0`.
- Inputs: 4.
- Outputs: 2.
- Declared states: 0.
- Configurable parameters: 0.
- The imported definition is fully supported by the Dynamic Editor catalogue.

## Characteristic equations

$$
0 = (d - cosphi \cdot alpha + sinphi \cdot beta)
$$

$$
0 = (q - -sinphi \cdot alpha + cosphi \cdot beta)
