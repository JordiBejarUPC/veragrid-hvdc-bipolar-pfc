# Clarke transform

This is Basic Block Catalog type `534` (`Clarke transform`). It converts signals between the coordinate systems or units identified by the block name.

## Behaviour

- Library location: `Native / Transforms / Clarke, Park and dq0`.
- Inputs: 3.
- Outputs: 3.
- Declared states: 0.
- Configurable parameters: 0.
- The imported definition is fully supported by the Dynamic Editor catalogue.
