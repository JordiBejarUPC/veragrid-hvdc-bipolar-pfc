# PQ Calculator

This is Basic Block Catalog type `115` (`PQ Calculator`). It processes measurement or control signals for use inside a dynamic control model.

## Behaviour

- Library location: `Native / Control and Measurement / Measurements and Units`.
- Inputs: 4.
- Outputs: 2.
- Declared states: 0.
- Configurable parameters: 0.
- The imported definition is fully supported by the Dynamic Editor catalogue.
