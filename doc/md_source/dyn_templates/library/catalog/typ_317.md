# Limit (parameter) [param: y_lim]

This is Basic Block Catalog type `317` (`Limit [p]`). It applies the declared limiting or nonlinear relation to its input signals.

## Behaviour

- Library location: `Native / Limits and Nonlinearities / Limiters`.
- Inputs: 1.
- Outputs: 1.
- Declared states: 0.
- Configurable parameters: 1.
- The imported definition is fully supported by the Dynamic Editor catalogue.

## Characteristic equations

$$
0 = (yo - -y_{lim} + (yi - -y_{lim}) \cdot \Theta\left(yi - -y_{lim}\right) - (yi - y_{lim}) \cdot \Theta\left(yi - y_{lim}\right))
$$
