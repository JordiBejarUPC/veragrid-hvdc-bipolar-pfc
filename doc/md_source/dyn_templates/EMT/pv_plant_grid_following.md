# PV plant grid following

This model represents a grid-following PV plant in EMT form.

## Interface table

| Category | Name | Meaning | Units |
| --- | --- | --- | --- |
| Input | `v_A` | Instantaneous phase-A AC terminal voltage seen by the PV converter | pu |
| Input | `v_B` | Instantaneous phase-B AC terminal voltage seen by the PV converter | pu |
| Input | `v_C` | Instantaneous phase-C AC terminal voltage seen by the PV converter | pu |
| Output | `i_A` | Phase-A current injected by the PV plant into the EMT network | pu |
| Output | `i_B` | Phase-B current injected by the PV plant into the EMT network | pu |
| Output | `i_C` | Phase-C current injected by the PV plant into the EMT network | pu |
| Variable | `P_avail` | Active-power availability computed from irradiance, temperature, and PV-side limits | pu |
| Variable | `P_mppt` | Active-power command produced by the MPPT-related logic before converter limits are applied | pu |
| Variable | `vdc` | Internal DC-link voltage of the imported averaged VSC block | pu |
| Variable | `theta_pll` | Internal PLL phase angle used by the grid-following converter controls | rad |
| Variable | `omega_pll` | Internal PLL frequency estimate used by the grid-following converter controls | pu |
| Variable | `i_d_ref` | d-axis current reference generated by the outer active-power or DC-voltage control loop | pu |
| Variable | `i_q_ref` | q-axis current reference generated by the outer reactive-power or voltage-related control loop | pu |
| Parameter | `irradiance` | Solar irradiance input used by the PV availability model | W/m^2 |
| Parameter | `temperature` | PV cell temperature used by the PV availability model | degC |
| Parameter | `P_rated` | Rated active power of the PV plant model | pu |
| Parameter | `omega_base` | Base electrical angular frequency used by the imported converter controls | rad/s |
| Parameter | `k_p_pll` | Proportional gain of the imported PLL controller | pu/pu |
| Parameter | `k_i_pll` | Integral gain of the imported PLL controller | pu/(pu s) |
