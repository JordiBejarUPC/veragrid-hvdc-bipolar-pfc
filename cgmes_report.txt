WHAT IS AND ISN'T IMPLEMENTED
------------------------------

  - AC lines, 2- and 3-winding transformers, ratio/phase tap changers

  - Linear and nonlinear shunt compensators, SVCs
  - HVDC (VSConverter, ACDCConverter, DCLineSegment)
  - State variables (SV profile: voltage, power flow, tap step)
  - Geographical location (GL profile)
  - Boundary sets (EQ_BD, TP_BD)

IMPORT/EXPORT WORKFLOW
-----------------------

Import (CGMES -> VeraGrid):
  1. User opens CGMES ZIP file
  2. CgmesDataParser extracts and parses RDF/XML
  3. CgmesCircuit builds object model with reference resolution
  4. cgmes_to_veragrid converter creates MultiCircuit with:
       - Buses (from TopologicalNode)
       - Lines / Transformers
       - Generators / Loads
       - Controls and limits
       - State variables (voltage, power flow)

Export (VeraGrid -> CGMES):
  1. User selects export options (version, profiles, boundary set)
  2. veragrid_to_cgmes converter creates CGMES objects
  3. CgmesCircuit aggregates the converted objects
  4. CimExporter serializes to RDF/XML
  5. Files packaged in ZIP with proper structure
